# Artificial intelligence
Artificial intelligence is the study of computational systems that perform tasks associated with intelligence, including reasoning, learning, perception, and language. Machine learning is a branch of AI that learns patterns from data rather than relying only on hand-written rules. Supervised learning uses examples paired with labels. Unsupervised learning seeks structure without target labels. Deep learning uses neural networks with multiple layers to learn representations. Training adjusts model parameters, while inference applies learned parameters to a new input. A study application can run inference with existing models and does not need to train a large model itself.

# Natural language processing
Natural language processing is a field of artificial intelligence that studies how computers process human language. NLP combines computational methods with knowledge about linguistic structure. Typical applications include document classification, machine translation, search, question answering, and summarization. Educational tools can use these methods to organize notes and help students practice recalling important concepts. Language is difficult to model because the same word can have different meanings in different contexts, and readers often rely on information that is not explicitly written.

# Preprocessing
Tokenization is the process of dividing text into smaller units called tokens. A token may be a word, a punctuation mark, or a piece of a word. Subword tokenization allows a model to represent unfamiliar words using smaller pieces from a fixed vocabulary. Sentence segmentation identifies boundaries between sentences. This task must handle abbreviations, decimal numbers, and punctuation carefully. Whitespace normalization removes unnecessary spaces without changing the meaning of the text. Aggressively removing punctuation and stopwords before transformer inference can damage the relationships between words.

# Embeddings and similarity
Embeddings are numerical vectors that represent words, phrases, or passages. Similar meanings often correspond to vectors that are close together in an embedding space. Contextual embeddings change according to the words surrounding a token. For example, the word bank has different representations in a passage about a river and a passage about money. Cosine similarity measures the alignment of two vectors. A high similarity score suggests related meaning, but it does not prove that a statement is true or that two statements agree in every detail.

# Transformer architecture
Transformers are neural network architectures that use attention to process sequences. Unlike a recurrent network, a transformer does not require every token to be processed sequentially through a recurrent state. Positional information helps the model represent token order. A transformer layer usually contains an attention mechanism and a feedforward network, with normalization and residual connections supporting stable computation. Models learn parameters during pretraining on large text collections. A student project can apply a pretrained transformer without training a large language model from scratch.

# Attention
Attention allows a model to assign different weights to different parts of an input sequence. Self-attention compares tokens within the same sequence to build context-sensitive representations. Queries, keys, and values are vector projections used in the attention calculation. A query is compared with keys to produce weights, and those weights combine the value vectors. Multi-head attention uses several attention computations so the model can represent different relationships. Attention weights can be inspected, but they should not automatically be treated as a complete explanation of a model's prediction.

# BERT, GPT and T5
BERT is an encoder-based transformer model designed to learn bidirectional representations of text. During masked language modeling, selected tokens are hidden and the model predicts them using surrounding context. BERT can be adapted for tasks such as classification and extractive question answering. GPT is a decoder-based transformer family that predicts the next token from earlier tokens. Its autoregressive generation produces text one token at a time. Encoder-decoder models use an encoder to represent input text and a decoder to generate an output sequence. T5 frames many language tasks as text-to-text problems.

# Summarization
Text summarization produces a shorter version of a document while retaining important information. Extractive summarization selects existing sentences or passages. Abstractive summarization generates new wording and may combine information from several sentences. An abstractive summary can also omit details or introduce unsupported claims. Long documents require chunking because transformer models have finite context windows. Sentence-aware chunking groups complete sentences within a token budget. A sentence that exceeds the budget needs explicit handling rather than silent truncation. Summaries of separate chunks can be combined to cover the whole document.

# Concepts and questions
Keyword extraction identifies phrases that represent important topics in a document. KeyBERT uses embeddings to compare candidate phrases with text. Candidate generation and semantic ranking both affect the selected keywords. Question generation can turn a source-supported statement into a cloze question by hiding an important concept. Distractors are incorrect options presented alongside the correct answer in a multiple-choice question. Useful distractors belong to the same subject area but should not also complete the statement correctly. A question with several valid options is ambiguous and needs revision.

# Active recall
Active recall is the practice of retrieving information from memory rather than rereading it passively. Flashcards provide a prompt on one side and an answer on the other. Source evidence helps learners check the answer against their notes. Quiz accuracy is the number of correct answers divided by the number of attempted questions, multiplied by one hundred. This measures performance on that quiz rather than general intelligence or model accuracy. Spaced repetition schedules review sessions over time and is a possible extension to a study application.

# Evaluation
ROUGE evaluates overlap between a generated summary and a reference summary. ROUGE-1 compares individual words, while ROUGE-2 compares adjacent word pairs. ROUGE-L uses the longest common subsequence to capture shared word order. Precision describes how much generated content overlaps the reference, and recall describes how much reference content is covered. These metrics require an actual reference and should not be fabricated when none exists. Semantic similarity can supplement lexical overlap, but human review remains useful for checking factual support, clarity, question quality, and omitted information.
